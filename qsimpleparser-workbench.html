In your code

          
inputThe text from the Input pane.

          
print(a, b, …)Writes a line to Console. console.log does the same.

          
last expressionIts value appears under Result. A parser shows all its matches, highlighted in the input.

        

        

          
Make a parser

          
chaR('a')One character (or a character code).

          
string('abc', caseSensitive = true)A literal string.

          
pattern('a-zA-Z_')One character from a regex character class.

          
letter()  digit()  word()Letter, digit, letter or digit.

          
space()  spaceOptional()One or more / zero or more whitespace characters.

          
newLine()A line feed.

          
firstChar()  lastChar()The first or last character of the input.

          
remainingChars()  allInput()Everything to the end / the whole input.

          
any(end, except?)Any character while end still occurs later. except is a character-class body such as 'a-z'.

          
charsBefore(p)Every character up to the first match of p.

          
wrap(p)  debug()Delegate to another parser / log the position.

        

        

          
Combine

          
p.seq(q)  p.and(q)p followed by q.

          
p.or(q)  p.oR(q)p, or q if p fails.

          
p.optional()Zero or one match.

          
p.star()  p.plus()Zero or more / one or more.

          
p.repeat(min, max = -1)Between min and max matches. Without max, exactly min.

          
p.skip()Consume a match at the start without keeping it.

        

        

          
Run

          
p.parse(input, start = 0)Match exactly at start. Returns a Result.

          
p.firstMatch(input, start)First Result at or after start.

          
p.firstStringMatch(input, start)Its text, or an empty string.

          
p.lastMatch(…)  p.lastStringMatch(…)The last match.

          
p.allMatches(…)  p.allStringMatches(…)Every non-overlapping match, as Success objects / strings.

          
p.hasMatch(input, start)true or false.

          
p.replaceIn(input, text, start, count)Replace matches. count = -1 replaces all.

          
p.replaceInMapped(input, fn, start, count)Replace each match with fn(matchText).

          
p.removeFrom(input, start, count)Delete matches.

        

        

          
Results

          
r.isSuccess()  r.isFailure()Which one it is.

          
r.success()A Success with .value(), .start(), .end().

          
r.failure()A Failure with .position(), .message().

        

        

          
Custom parsers

          
class X extends ParserCall super('X'), implement parseOn(ctx) using ctx.buffer() and ctx.position(), and return succeed(start, end) or fail(position, message).
